# ЛР 2 — обоснование актуальности ВКР

**Тема ВКР:** Разработка модели машинного обучения для анализа торговых паттернов с учетом новостного фона.

**Автор:** Михайлов Юрий

**Вклад автора:** Разработка модели машинного обучения, которая получает на входе различные маркеры (SMC-структура, зоны, новостные события) и формирует вероятностное распределение сценариев по сделке. В зону ответственности входят нормализация и кодирование входных данных, выбор и обучение моделей, интерпретация результатов. Получение первичных маркеров по графику и их визуализация выполняются другими участниками проекта.

### Выводы по обзору

Анализ литературы показывает, что паттерны и сигналы можно превратить в формальные признаки и использовать их для прогнозов [1], [3]. В моей части проекта эти признаки - SMC-структура, зоны и новостные события. С их помощью модель машинного обучения может строить не один точечный прогноз, а распределение возможных сценариев по сделке. Работы [4] и [5] подтверждают, что такой вероятностный подход технически реализуем и позволяет оценивать уверенность модели, а не только направление движения. При этом ни один из источников не даёт оснований считать данные методы гарантией прибыли.

Работа [2] показывает, что новостной фон связан с последующей динамикой рынка, поэтому новостные события должны попадать в модель как признаки с временной привязкой и контекстом, а не как отдельный список.

Русскоязычные источники добавляют вопросы обработки данных и устойчивости алгоритмов [6]–[9], а [10] и [11] дают базу по временным рядам. В итоге литература покрывает данные, алгоритмы, ML-модели и проверку результатов.

### Выводы по сравнению аналогов

Сравнение показывает, что каждый из рассмотренных продуктов закрывает часть нужной задачи. TradingView хорошо решает задачу построения графика и пользовательского анализа. TrendSpider ближе к нашей теме по автоматическому поиску паттернов, сезонности и внедрению моделей машинного обучения. Bookmap и Exocharts полезны как примеры работы с ликвидностью и потоком ордеров, но у них другой основной сценарий.

В данном случае разрабатывается инструмент, который принимает на входе формализованные маркеры (SMC-структуру, зоны, новостные события), выполняет нормализацию и кодирование, а затем с помощью модели машинного обучения формирует вероятностное распределение сценариев по сделке. Это не попытка заменить профессиональные платформы, а специализированное решение для учебного и исследовательского проекта, где основное внимание уделяется корректной обработке признаков и интерпретации результатов модели.

## 4. Итоги

**Итоговая тема ВКР:** Разработка модели машинного обучения для анализа торговых паттернов с учетом новостного фона.

**УДК для тезиса:** 004.42 — разработка программного обеспечения. Окончательный индекс требуется согласовать с научным руководителем.

**Ключевые слова:** Машинное обучение; ML; алгоритмический анализ; прогнозирование; торговые сигналы; Smart Money Concept; новостной фон; вектор признаков; Random Forest; XGBoost; бэктестинг.

### Актуальность исследования

Алгоритмический трейдинг требует быстро учитывать разные данные: ценовые ряды, SMC-маркеры ликвидности и макроэкономические новости. Классические индикаторы не всегда выявляют сложные нелинейные зависимости, а ручное сопоставление SMC-паттернов с новостным фоном повышает нагрузку и риск ошибок.

Существующие платформы автоматизируют это лишь частично. TradingView позволяет задавать алгоритмические сигналы, но не обучает ML-модели на пользовательских признаках. TrendSpider имеет инструменты ML, однако использует стандартные индикаторы, а не формализованные SMC-маркеры, и новостной контекст по умолчанию не входит в модель.

Поэтому актуальна разработка модели машинного обучения, которая получает SMC-маркеры и новостные события, нормализует и кодирует их в единый вектор признаков, а затем формирует вероятностное распределение сценариев по сделке (лонг / шорт / нет сигнала) с интерпретацией вклада признаков.

Практическая значимость — ML-модуль для учебно-исследовательского финтех-проекта. Ансамблевые методы (Random Forest / XGBoost) позволяют проверять устойчивость формализованных торговых признаков на исторических данных. Решение позиционируется как инструмент поддержки решений и верификации сценариев, а не как гарантия доходности.

### Цель исследования

Проектирование и разработка модели машинного обучения для анализа торговых паттернов и маркеров, получаемых алгоритмически из графиков цен торгуемых пар активов, а также построения связи с новостным фоном в интересах поддержки принятия решений на финансовых рынках.

### Задачи исследования

1. Формализовать преобразование готовых SMC-маркеров и событий макроэкономического календаря в числовые признаки. Включает нормализацию, кодирование признаков и сборку единого вектора для модели.
2. Исследовать и выбрать методы машинного обучения для классификации финансовых временных рядов, а также определить их ограничения в условиях рыночного шума.
3. Разработать слой, использующий модель машинного обучения, и выдающий для сделки вероятностное распределение классов "лонг", "шорт", "нет сигнала".
4. Реализовать обучение моделей на скользящем историческом окне, а также извлечение весов признаков для интерпретации вклада различных признаков.
5. Провести валидацию на отложенном временном отрезке: рассчитать метрики классификации, проверить устойчивость к смене рыночных режимов и скорость генерации сигналов, а также исключить "заглядывание в будущее".

### Датасеты и сервисы

1. **Исторические ценовые данные (OHLCV):** XAUUSD, EURUSD, GBPUSD. Источник — брокерский API (конкретный провайдер уточняется).
2. **Размеченные данные SMC:** готовые маркеры (ликвидность, FVG, Order Blocks, BOS/CHoCH и др.), предоставляемые другими участниками команды. ML-слой не извлекает их из сырых цен.
3. **Экономический календарь:** Forex Factory — дата/время, валюта, важность, название события, прогноз, предыдущее и фактическое значение.
4. **Сезонные признаки:** исторические ряды за несколько лет, сгруппированные по активу и календарному признаку.

**Ограничение по временной доступности:** при формировании признаков для обучения и валидации учитывается, что фактические значения новостей и подтверждения SMC-структуры не могут использоваться до момента их публикации / формирования. Для исторического календаря фиксируется время выхода и используются только опубликованные значения.
