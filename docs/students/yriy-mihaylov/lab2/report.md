# ЛР 2 — обоснование актуальности ВКР

**Тема ВКР:** Проектирование и разработка модели машинного обучения для анализа торговых паттернов и маркеров, получаемых алгоритмически из графиков цен торгуемых пар активов, а также построения связи с новостным фоном.

**Автор:** Михайлов Юрий

**Вклад автора:** Проектирование и реализация ML-моделей, которые получают на входе готовые маркеры (SMC-структура, зоны, новостные события), преобразуют их в вектор признаков и формируют вероятностное распределение сценариев. В зону ответственности входят нормализация и кодирование входных данных, выбор и обучение моделей, интерпретация результатов. Получение первичных маркеров по графику и их визуализация выполняются другими участниками проекта.

### Выводы по обзору

Анализ научной литературы показывает, что разработка автоматизированных торговых систем смещается от жестких индикаторов к адаптивным методам машинного обучения (Deep Learning) и объяснимому искусственному интеллекту (XAI). Исследования подтверждают, что геометрические концепции (к которым относится Smart Money Concept) поддаются математической формализации с помощью сверточных архитектур и алгоритмов поиска аномалий.
Однако ключевой проблемой современных ML-решений в трейдинге остается их непрозрачность («эффект черного ящика») и высокая чувствительность к макроэкономическим шокам.

- [TradingView](https://www.tradingview.com/) - веб-платформа с интерактивными графиками, индикаторами, пользовательскими скриптами на Pine Script, стратегиями с бэктестером и алертами. Прямой аналог по визуальному анализу рынка.

- [Bookmap](https://bookmap.com/) - визуализация ликвидности и потока ордеров через heatmap, объёмные пузыри и DOM.

### Выводы по сравнению аналогов

TradingView предоставляет алгоритмические сигналы через Pine Script, но не обучает ML-модели на пользовательских признаках. TrendSpider даёт ML-обучение без кода, однако входной вектор строится из стандартных индикаторов и формул, а не из формализованных SMC-маркеров в сочетании с новостным контекстом. Bookmap и Exocharts фокусируются на микроструктуре и не решают задачу интеграции SMC-геометрии с макроэкономическим фоном в единый признаковый вектор.

Отличие разрабатываемого ML-слоя: входные признаки формируются из готовых SMC-маркеров (Order Blocks, FVG, структура) и закодированных весов новостных событий; модель интерпретируема (RF/XGBoost с feature importance), а выход представляет вероятностное распределение сценариев, а не бинарный вердикт.

## 4. Итоги

**Итоговая тема ВКР:** Проектирование и разработка модели машинного обучения для анализа торговых паттернов и маркеров, получаемых алгоритмически из графиков цен торгуемых пар активов, а также построения связи с новостным фоном.

**УДК для тезиса:** 004.42 — разработка программного обеспечения. Окончательный индекс требуется согласовать с научным руководителем.

**Ключевые слова:** Машинное обучение; ML; алгоритмический анализ; прогнозирование; торговые сигналы; Smart Money Concept; новостной фон; вектор признаков; Random Forest; XGBoost; бэктестинг.

### Актуальность исследования

Современный алгоритмический трейдинг требует оперативной обработки разнородной информации: ценовых рядов, геометрических маркеров ликвидности, макроэкономических новостей. Классические индикаторы часто не выявляют сложные нелинейные зависимости, а ручное сопоставление SMC-паттернов с новостным фоном повышает когнитивную нагрузку и риск ошибок.

Существующие платформы частично автоматизируют эти процессы. TradingView предоставляет алгоритмические сигналы через Pine Script, но не обучает ML-модели на пользовательских признаках. TrendSpider содержит ML Quant Lab с обучением моделей без кода, однако входной вектор строится из стандартных индикаторов, а не из формализованных SMC-маркеров, и новостной контекст не входит в модель по умолчанию.

Актуальность разработки заключается в построении модели машинного обучения, которая принимает готовые SMC-маркеры и новостные события, преобразует их в единый вектор признаков и формирует вероятностное распределение сценариев (лонг / шорт / нет сигнала) с возможностью интерпретации вклада каждого признака.

Практическая значимость: модуль машинного обучения для учебно-исследовательского финтех-проекта. ML-слой на базе ансамблевых методов (Random Forest / XGBoost) позволяет проверять устойчивость формализованных торговых признаков на исторических данных. Продукт позиционируется как инструмент поддержки принятия решений и верификации сценариев, не гарантирующий доходность.

### Цель исследования

Спроектировать и разработать ML-слой, который принимает готовые SMC-маркеры и данные новостного календаря, преобразует их в вектор признаков и формирует вероятностное распределение торговых сценариев (лонг / шорт / нет сигнала) с интерпретацией вклада признаков.

### Задачи исследования

1. Формализовать схему преобразования готовых SMC-маркеров (Order Blocks, FVG, структура, зоны), предоставляемых командой, в числовые признаки для ML-модели, включая нормализацию и кодирование.
2. Исследовать методы машинного обучения для классификации финансовых временных рядов и определить ограничения в условиях высокого рыночного шума.
3. Разработать пайплайн предобработки и нормализации готовых маркеров для корректной подачи в модель.
4. Разработать алгоритм кодирования категориальных факторов макроэкономического календаря (важность, валюта, время до/после события) для интеграции в общий вектор признаков.
5. Спроектировать архитектуру ML-слоя на базе ансамблевых моделей (Random Forest / XGBoost) для оценки вероятностей классов «лонг», «шорт», «нет сигнала».
6. Реализовать модуль обучения и динамического переобучения моделей на скользящем историческом окне.
7. Реализовать извлечение весов признаков (feature importance) для интерпретации вклада SMC-маркеров и новостных факторов в итоговое распределение.
8. Провести валидацию моделей на отложенном временном отрезке с расчётом метрик качества классификации и калибровки вероятностей.
9. Проверить устойчивость алгоритмов к смене рыночных режимов и оценить скорость генерации сигналов.

### Датасеты и сервисы

1. **Исторические ценовые данные (OHLCV):** XAUUSD, EURUSD, GBPUSD. Источник — брокерский API (конкретный провайдер уточняется).
2. **Размеченные данные SMC:** готовые маркеры (ликвидность, FVG, Order Blocks, BOS/CHoCH и др.), предоставляемые другими участниками команды. ML-слой не извлекает их из сырых цен.
3. **Экономический календарь:** Forex Factory — дата/время, валюта, важность, название события, прогноз, предыдущее и фактическое значение.
4. **Сезонные признаки:** исторические ряды за несколько лет, сгруппированные по активу и календарному признаку.

**Ограничение по временной доступности:** при формировании признаков для обучения и валидации учитывается, что фактические значения новостей и подтверждения SMC-структуры не могут использоваться до момента их публикации / формирования. Для исторического календаря фиксируется время выхода и используются только опубликованные значения.
